геометрия приемлема. В S3 нет GPIO22…25 — поэтому SCL 22 и MOSI 23 перенести один-в-один нельзя.

## 4. Правки прошивки (не применяются в этом цикле, только документируются)

`kamaz_2_16_8_fr_adafruiti_OTA_NM/app_pins.h`:
```
PIN_OLED_SCL  22 -> 47
PIN_TFT_MOSI  23 -> 11
PIN_TFT_RST   19 -> 17   // на новой плате это /DISP_RES
```
Пины клапанов (32/33/25/26/27/14) и кнопок (13/12/15/17/34) в новой плате не используются вообще:
клапаны и кнопки идут через PCAL9555A (/VLV_EN + I2C + /INT_MCU). Это отдельная работа по прошивке.

## 5. Запреты

- Переименовывать цепи нельзя: имена `/DISP_*`, `/I2C_*`, `/VLV_EN`, `/INT_MCU`, `/PRES_SW`,
  `/SPEED_PULSE` остаются байт-в-байт.
- Менять местами питание (пады 1, 2, 21, 22, 23, 43, 44) нельзя.
- Медь в полосе антенны (x 103,0…104,05 при y 15,40…38,26): 0 дорожек, 0 переходов, 0 вершин заливки.
- Позиции J1…J8 и H1…H4 не меняются. Другие проекты (`hardware/kicad`, `variants/devkitv1`) — только чтение.
