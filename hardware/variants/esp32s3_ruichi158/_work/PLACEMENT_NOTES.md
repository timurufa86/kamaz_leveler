# esp32s3_ruichi158 — плата 60 x 85,5, только расстановка (без меди)

Источник: `../esp32s3` (вариант A). Схема/проект/библиотеки скопированы как есть
(в .kicad_sch/.pro/.prl заменено только имя проекта: kamaz_leveler_s3 -> kamaz_leveler_ruichi158).

## Что сделано
1. `_work/strip.py` — текстовая хирургия .kicad_pcb: удалены 906 segment + 283 via + 3 zone,
   8 объектов Edge.Cuts, футпринты H1..H4. Осталось 116 футпринтов, 0 меди, 0 контура.
2. `_work/build.py` — рисование нового контура (16 отрезков + 8 трёхточечных дуг) и
   применение расстановки из `_work/placements.json`.
3. `_work/pack.py` — расстановка: сетка 0,1 мм, numpy-prefix occupancy, приоритет по площади,
   привязка к цепям (не глобальные) и к «своей» ИС по выводу питания в варианте A.
   Запреты внутри пакера: край платы 0,3 мм (разъёмы 0,1), пазы R3,75+0,5, полоса антенны,
   двор модуля на верхнем слое, сквозные пазы THT на противоположном слое.
4. `_work/report.py` — независимая проверка по сохранённой плате.

## Числа приёмки
- Edge.Cuts: bbox ровно 60,0000 x 85,5000 мм, центр (0,0); 24 объекта (16 линий + 8 дуг),
  каждый узел использован ровно 2 раза (контур замкнут).
- Дуги: 4 угла R3,0000 в (±27; ±39,75); 4 паза R3,7500 в (±27; ±29), вершина паза (±23,25; ±29).
- Футпринтов 116 (F 63 / B 53); дорожек 0, переходов 0, зон 0.
- DRC `_work/drc_place.txt`: 0 нарушений, 290 неподключённых (ratsnest — норма при отсутствии разводки).
- ERC `_work/erc.rpt`: 0 ошибок / 0 предупреждений. BOM: 116 позиций, 46 сгруппированных строк.
- Двор-пересечения в пределах слоя: 0 (мин. зазор 0,26 мм). Выход за контур: 0.
- Пазы: минимальное расстояние от любого двора/пада до центра дуги паза 4,30 мм => зазор до дуги 0,55 мм (>= 0,5).
- Антенная полоса (y >= 37,40, x -13..13): 0 футпринтов и 0 падов (пусто даже при 10 мм).
- U7: rot -90 (перпендикулярно исходному 0), двор [-12,995..12,995] x [-20,885..42,400], торец антенны на +Y.

## Осознанные отклонения
- J3..J6 стоят перпендикулярно верхней грани (тело внутрь): боковые полосы 16,55 мм уже длины
  J5 (21,41 мм), горизонтально разъём не влезает, а сдвиг модуля не даёт места у скруглений угла.
- U2 (верх -14,46), C28 (верх -14,11), D2 (-13,80), D3 (-13,95) — на 0..0,45 мм выше линии нижней
  трети (-14,25). Все 8 деталей, названные в п.3 правил (U1, U2, D1, F1, L4, C28, C2, Q1), лежат
  в нижней трети; для D2/D3 свободного места 9,89 x 6,79 мм в нижней трети нет (свободно 365 мм2,
  фрагментировано; проверено полным перебором и перебором с вытеснением соседей).
- Позиционные обозначения на шёлке не разводились — местами перекрываются (DRC не нарушает).
