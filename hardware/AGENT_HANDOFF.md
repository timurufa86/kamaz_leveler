### ВАЖНО: что скрыто за waivers

«0 нарушений» — это 0 при действующих пяти waiver-типах. Если их снять, плата показывает
**284 замечания**, все косметические или механические:

| Тип | Кол-во |
|---|---|
| silk_over_copper | 120 |
| silk_overlap | 96 |
| courtyards_overlap | 65 |
| silk_edge_clearance | 2 |
| lib_footprint_issues | 1 |

`lib_footprint_issues` — это H1..H4: футпринт называется `MountingHole_3.2mm_M3_Pad6`, но пады
в нём переделаны под Ø2,2 NPTH. Имя не соответствует геометрии. На производство не влияет
(сверловка и медь корректны), но при правке платы помните об этом.

Электрика при снятых waivers остаётся **0/0** — то есть ни замыканий, ни нарушений зазоров,
ни несоединённых цепей waiver-настройки не маскируют.

## 4. Известные особенности, НЕ считать дефектами

1. **Ширины силовых трасс.** 24,89 мм суммарно ниже ширины своего netclass, все — короткие
   пережимы, каждый на измеренном геометрическом максимуме:
   `+12V` 159,85 мм на 0,600 и 14,16 мм ниже (из них 11,76 на 0,55; 2,04 мм на 0,35);
   `+3V3` 1,12 мм из 211; `+5V` 2,35 мм из 81; `/VALVE_BUB4` 3,53 мм из 61;
   `/VALVE_BUB2`, `DEFL`, `INFL` 0,78..1,52 мм. Причина: U6 — TSSOP с шагом 0,65 мм и падами
   0,40 мм, поэтому любая трасса, выходящая из его пада, ограничена 0,65 - 0,127 = 0,523 мм;
   0,8 мм там арифметически невозможны. Правило `track_width` (минимум 0,15) не нарушено.
   Худшее место — два куска `+12V` по 0,35 мм длиной 1,63 и 0,41 мм, окружённые широкой медью:
   при 3 А рассеивается около 25 мВт, перегрева нет.
2. **Антенная зона.** В полосе антенны (y 11..43) медь доходит только до x = 100,150 — это
   собственные пады модуля U7-14/15/16/17, которые обязаны быть подключены. Область x 101..104
   полностью свободна от меди. Максимум меди по X на всей плате 103,500 достигается при y = 3,0,
   то есть далеко вне антенной полосы.
3. **`via_dangling`** отсутствует (на старой плате была одна ложная на `/DISP_BL`).
4. **`schematic-parity` = 4** — монтажные отверстия H1..H4 отсутствуют в схеме. Это было и на
   исходной плате, не регресс. Чинить = править схему ради четырёх NPTH, которых в BOM нет.
5. **`lib_footprint_issues` = 1** — имя футпринта H1..H4 (`MountingHole_3.2mm_M3_Pad6`) не
   соответствует переделанным падам Ø2,2 NPTH. На производство не влияет.
6. Полигоны GND: вырез под антенну с x 95,5 в полосе y 10,5..43,5; 85 из 90 падов земли
   подключены полигоном, 4 получили локальное сплошное подключение, 1 — короткий вывод.

## 8. Грабли (проверено на практике, экономит часы)

**pcbnew / SWIG**

- `pcbnew.SaveBoard()` на плате, лежащей **вне папки проекта**, перезаписывает `.kicad_pro`
  значениями по умолчанию: теряются netclasses и `rule_severities`, DRC даёт 801 нарушение
  вместо 0. Лечить: сохранять только на месте, из папки проекта, и после каждого сохранения
  сверять отпечаток `.kicad_pro` (20994 байта, sha256 `1ed98c56..c34c6c7`).
- `Pad.GetEffectivePolygon()` и `GetEffectiveShape()` **требуют аргумент слоя** — иначе молча
  возвращаются неповёрнутые прямоугольники падов и все выводы о зазорах неверны.
- Отверстия блокируют переходные отверстия **без учёта цепи** (`hole_to_hole` 0,25).
- `BOARD.GetUnconnectedCount` в этом биндинге **отсутствует** — считать через DRC.
- `PCB_VIA.GetWidth()` требует слой. `VECTOR2I(FromMM(x), FromMM(y))`, не `FromMM(*tuple)`.
- `FOOTPRINT.GetBoundingBox(False,False)` не центрирован относительно позиции футпринта.
- После `board.Remove(t)` объект платы может испортиться — удалять отдельным процессом.
- MSYS2 портит argv, похожий на путь (с ведущим «/»). Имена цепей держите внутри скрипта.
- Модель зазоров держите с запасом ~0,006 мм и ВСЕГДА сверяйте её с реальным DRC.

**Правила KiCad**

- Ширина трассы в netclass — значение **по умолчанию**, а НЕ правило. Трасса уже своего класса
  не даёт `track_width`. Именно так `+12V` оказалась разведена 0,35 мм при классе 0,60.
- Членство в netclass задаётся в `.kicad_pro -> net_settings.netclass_patterns`; массивы `nets`
  в классах ПУСТЫ — не обманывайтесь.
- `kicad-cli sch erc` кладёт ошибки в `sheets[0].violations`.
- `--severity-all` и `--severity-exclusions` показывают скрытое.
- `schematic-parity` даёт `extra_footprint` на монтажные отверстия, которых нет в схеме.

**Метод (самое главное)**

- **Землю разводить полигоном, а не трассами.** У GND 90 падов; полигон на двух слоях забрал
  85 из них сам. Это и решило задачу, которую расчёт расстановки оценивал в 5-12 несоединённых.
  Прогресс по земле был 80 -> 19 -> 8 -> 1 -> 0 (181 переходное отверстие + связи островов).
- FreeRouting на чистой плате дал 199 из 202 соединений; остаток добивался через A* с точной
  геометрией. Раньше на уже разведённой плате он же выдавал 490 нарушений — импортировать
  только с проверкой DRC.
- Локальный поиск врёт: `/VIN_FUSED` дважды объявляли заблокированной, искав в рамке; полный
  поиск по плате дал путь. Длинный обход — законный результат.
- Если исполнитель говорит «невозможно» — проверять, не переусложнил ли он ограничения.
  Три «невозможно» в этой сессии были следствием лишних требований.
