# Сверка наличия компонентов: chipdip.ru и magazin-elektronika.ru

Документ проекта **kamaz_leveler** (платы уровня пневмоподвески КАМАЗ).
Правило перенесено из проекта antenna_rotator (C:\my\for cursor\antenna_rotator\docs\SOURCING.md)
без изменений по существу; ниже — его формулировка, метод проверки, обе ловушки и результат,
измеренный именно для плат уровня.

## Правило проекта

**Любая новая деталь сначала проверяется по наличию в chipdip.ru и/или magazin-elektronika.ru,
и только потом попадает в схему и в BOM.**

Порядок действий при добавлении позиции:

1. Найти MPN и корпус в даташите, проверить, что корпус есть в библиотеке KiCad.
2. Проверить наличие в магазине методом из раздела «Как проверять программно» (chipdip — HTTP,
   magazin-elektronika — только реальный браузер).
3. Записать результат в таблицу «Сверено» этого файла: позиция, магазин, точное обозначение
   товара, дата проверки.
4. Только после этого — в схему, в BOM и в производственные файлы.

**Деталь, которую никто не продаёт, превращает готовую плату в макет.** Плата, проверенная
DRC 0/0 и ERC 0, с деталью, которой нет в продаже, — это не изделие, а демонстрационный образец:
её нельзя повторить, её нельзя отдать в серию, и её нельзя починить заменой. Поэтому проверка
наличия — не бюрократия, а такой же этап проектирования, как DRC.

## Магазины

| Магазин | Что закрывает | Особенности |
|---|---|---|
| **chipdip.ru** | почти весь BOM, включая специализированные позиции и модули ESP32 | есть карточки с номерами; часть карточек без характеристик — проверять глазами |
| **magazin-elektronika.ru** | ходовые позиции (пассив, диоды, стабилизаторы, часть модулей) | модули разработчика этого класса не возит; поиск работает только через реальный браузер |

Стратегия: основная закупка — chipdip одной корзиной, второй магазин — резерв по ходовым позициям.

## Как проверять программно

### chipdip.ru — работает обычный HTTP

URL: https://www.chipdip.ru/search?searchtext=MPN

Признак наличия: в ответе есть ссылки /product/slug, где slug содержит нормализованный MPN
(например lm2596s-adj-d2pak-5-nsc-8075985390).

**Ловушка (контрольный запрос).** Метод обязательно проверять запросом-мусором: ZZZQQQXXX.
Контроль должен дать HTTP 404 и ноль карточек товара. **Если контроль даёт ненулевой результат —
метод сломался, и результатам верить нельзя**, даже если они выглядят правдоподобно.

### magazin-elektronika.ru — только через реальный браузер

URL: https://magazin-elektronika.ru/catalog?search=MPN

**Ловушка (эхо запроса).** Страница отдаёт эхо поискового запроса в HTML — 2…5 вхождений —
**независимо от того, есть товар или нет**. Подсчёт вхождений строки запроса даёт 100 % ложных
срабатываний: проверено на строке ZZZQQQXXX, она дала те же 2 вхождения, что и реальные детали.
Автоматическая проверка этого магазина по HTML непригодна.

Правильный способ: открыть страницу **в реальном браузере** (JavaScript должен отработать) и искать
**названия товаров**, а не токен запроса. Признак наличия — строки вида:

    LM2596DS-ADJ, Микросхема, D2PAK-5, ON Semiconductor
    SS14, Диод, DO-214AC, Hottech
    ESP32-C3-Zero, Плата разработчика

Признак отсутствия — только блок «Найдено в категориях» с эхом запроса, без карточек товара.

## Цены

Ни один из сайтов не отдаёт цены в статическом HTML (рендерятся скриптами). Цену смотреть на
странице товара; для прикидки использовать цены JLCPCB из ProtoFlow (защитная мелочь
0,02…0,25 USD, дроссель ~0,25 USD, стабилизатор ~0,63 USD).

## Сверено для плат уровня (05.11.2026)

Проверка выполнена для позиций, которые отличают три готовые платы уровня друг от друга
(база kamaz_leveler_hw, вариант A kamaz_leveler_s3, вариант B kamaz_leveler_devkitv1).

| Позиция | chipdip.ru | magazin-elektronika.ru | Вывод |
|---|---|---|---|
| AMS1117-3.3, код **C6186** | **есть** | **есть** | брать любую из двух; на всех трёх платах это U8 |
| 10uF 1206 | **есть** — CL31B106KAHNNNE, X7R, 25 В | **есть** — GCJ31CL8EF106KA08L, X8L | оба годятся; X7R предпочтительнее по температурной стабильности, X8L — по ёмкости при нагреве |
| 100nF 0805 | **есть** — GRT21BR71H104KE01L, X7R, 50 В | **есть** — CL21B104KBFNNCE, X7R | равнозначны |
| **ESP32-S3-DevKitC-1 N16R8** | **НЕТ** | **НЕТ** | именно N16R8 не купить ни в одном магазине |
| ESP32-S3-DEVKITC-1-N8R8, номенклатура **8049220070** | **есть** (взамен N16R8) | нет | та же 44-контактная плата, различие только в объёме памяти (8 МБ flash / 8 МБ PSRAM) |
| ESP32-S3-DevKitC-1-N32R16V, номенклатура **8065919634** | **есть** (взамен N16R8) | нет | та же 44-контактная плата, различие только в памяти (32 МБ flash / 16 МБ PSRAM) |
| ESP32-S3-DevKitM-1 | **нет** | **нет** | это **двойник**, а не замена: 44 контакта, но **ДРУГАЯ распиновка** — в сокет варианта A встанет механически и не заработает. Не путать |
| ESP32 DevKit V1 (30 контактов, Type-C) | карточка **8076892521 есть, но БЕЗ характеристик** | этот класс модулей не возит | перед заказом **обязательно проверить глазами**: ровно 30 контактов и разъём Type-C. 38-контактная плата в сокет 2x15 не встанет |

### Что из этого следует для плат

- **Вариант A (ESP32-S3-DevKitC-1, 44 контакта).** Заказывать N8R8 или N32R16V: сокет и
  распиновка у них те же, что у N16R8, меняется только память. Прошивку и карту падов менять
  не нужно. Модуль DevKitM-1 не заказывать: другая распиновка.
- **Вариант B (ESP32 DevKit V1 Type-C, 30 контактов).** Карточка chipdip 8076892521 не содержит
  характеристик, поэтому решение принимается по фото и по факту получения: ровно 30 контактов,
  Type-C, межрядное расстояние 25,4 мм. 38-контактная плата (DevKit V1 в другой ревизии)
  в сокет 2x15 не встанет вообще, а плата с межрядным 22,86 мм не попадёт в отверстия.
- **База (ESP32-C3-DevKitC-02).** Позиция закуплена ранее, в этой проверке не участвовала.
