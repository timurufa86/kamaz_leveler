# Kamaz-Leveler 8.8.0 — настраиваемые параметры, ручной тест клапанов, калибровка IMU

Основа: 8.7.0. Тип изменения: **MINOR** (новые параметры и разделы меню; обратная
совместимость: `config.txt` форматов 1 и 2 читается — прежние 11 значений
подхватываются, новые поля получают значения по умолчанию; `wifi_config.txt` и
OTA-контракт `bin` + `sha256` не менялись).

## 1. Все новые настройки пишутся в конфиг и подгружаются при перезагрузке

- `CONFIG_FORMAT_VERSION` = **3**. Добавлено **25 полей**: 16 параметров меню,
  порог детектора MPU, 6 офсетов IMU и 2 угла программного нуля.
- Чтение: значение по умолчанию берётся из структуры `Config`, каждое поле
  проходит `constrain()` по диапазону спиннера — испорченный или старый файл не
  ломает логику; при `formatVersion > 3` загрузка отклоняется (как раньше).
- Запись: по «СОХРАНИТЬ»/Кн5 — `config.tmp` → проверка чтением → `config.txt`,
  предыдущая версия остаётся в `config.bak`; в Serial печатается дамп всех
  значений (`[CFG] …`) при старте и после сохранения.
- Применение без перезагрузки: `applyRuntimeSettings()` применяет яркость,
  политику подсветки, интервал кадра, пороги перерисовки и порог MPU сразу после
  сохранения (пороги авторежима/движения читаются из конфига в момент
  использования).
- Страница меню **«Настройки»** — живой просмотр значений из `config.txt`.

## 3. Раздел «IMU / MPU6050»

- **Обнулить углы** (с подтверждением Кн3/Кн4) — текущее положение становится
  нулём отсчёта; нуль хранится в конфиге и учитывается системой.
- **Калибровка офсетов** — библиотечные `CalibrateGyro()`/`CalibrateAccel()`
  (DMP на время калибровки выключается, затем перезапускается), 6 офсетов
  сохраняются в `config.txt` и **применяются при старте** в `initializeDMP()`.
  Ранее офсеты в прошивке не применялись вообще.
- **Диагностика MPU** — DeviceID, температура, углы (с учётом нуля), сырые
  `getMotion6` (ax…gz), офсеты, признак активной ошибки MPU.
- **Порог детектора** — аппаратный `setMotionDetectionThreshold` (20…255, было 100).

## 4. Ручной тест клапанов (раздел «Тестирование»)

- 6 выходов: **ПЛ, ПП, ЗЛ, ЗП, НАКАЧКА, СБРОС**.
- Кн1/Кн2 — выбор, **Кн3 удерживать — клапан открыт, отпустили — закрылся**,
  Кн4 — выход с закрытием всех клапанов.
- Страховочный таймаут 15 с на удержание; доступно только в РУЧНОМ режиме без
  ошибок и вне OTA; аварийная остановка (Кн4+Кн5) и выход всегда закрывают клапаны.

## 5. Прочее

- **Гашение подсветки** по бездействию N минут; первое нажатие только включает
  подсветку и не выполняет действие.
- **Интервал кадра дисплея** и **пороги перерисовки** (углы/давление) стали
  настраиваемыми; интервал применяется в цикле задачи дисплея.
- Зоны авторежима (грубая/точная/«стало хуже») и параметры детектора движения
  читаются из настроек в местах использования.

## Проверка и сборка

- Сборка: `arduino-cli` 1.5.1, ядро esp32 3.3.11, FQBN
  `esp32:esp32:esp32:PartitionScheme=custom,FlashSize=16M`, `--warnings none`,
  флаг `compiler.c.elf.extra_flags=-Wl,--allow-multiple-definition`.
- Итог сборки: **скетч 1 411 974 байт (8 % от 16 МБ)**, **глобальные переменные
  70 760 байт (21 %)**, свободно 256 920 байт. Рост к 8.7.0: +22 004 Б flash и
  +3 944 Б ОЗУ (25 новых полей конфига, раздел IMU, ручной тест клапанов,
  страница «Настройки», служебные экраны).
- В прошивке строка версии: `V 8.8.0 FreeRTOS OTA`.

## Установка

- Устройства на 16-МБ карте разделов обновляются по воздуху: меню → «Обновления» →
  «Установить последнюю» (или выбрав конкретную версию в списке).

## Вне рамок этого релиза

- Таблица калибровки датчиков давления и фильтр Калмана.
- Расширенные параметры Wi-Fi/OTA, пиннинг CA (сейчас `setInsecure()`, целостность
  обеспечивает SHA-256 релиза).

# История: 8.7.0

# Kamaz-Leveler 8.7.0 — меню из любого режима, раздел «Обновления», живой статус

Основа: 8.6.1. Тип изменения: **MINOR** (новые возможности; обратная совместимость:
`config.txt` и `wifi_config.txt` читаются как раньше, OTA-контракт `bin` + `sha256`
не менялся).

## 1. Меню открывается из любого режима и экрана

- Вход в меню — **удержание пары кнопок КН3 + КН4** (GPIO15 + GPIO17, 2 с).
  Работает в RUNNING, в режиме ошибок, на экране теста, в OTA-режиме и на экране
  выбора Wi-Fi. Удержание пары не мешает управлению подушками одиночными кнопками.
- **Аварийная остановка** осталась как была и имеет приоритет: удержание пары
  **КН4 + КН5** (GPIO17 + GPIO34, 2 с). Подсказки на всех экранах приведены в
  соответствие фактическим кнопкам (раньше текст говорил «КН3+КН4», хотя по коду
  это были КН4+КН5).
- Убраны все прочие способы входа в меню (короткое Кн4 в режиме ошибок, Кн4/Кн5 в
  OTA-режиме, авто-вход после Wi-Fi-скана). Короткие нажатия сохранили свои роли:
  Кн4 — «стоп теста», Кн3 — «выход из OTA-режима».

## 2. Навигация и вид меню

- Один раз нажали Кн3 — вошли в раздел; **Кн4 — «назад»** (GEM сам добавляет пункт
  «Назад» стрелкой, т.к. все подстраницы создаются с родителем).
- Исправлена колонка значений: `menuValuesLeftOffset` 15 → 150 px, поэтому заголовки
  пунктов-значений больше не обрезаются до одной буквы.
- В шапке меню — подсказка по кнопкам: «КН3-ОК КН4-НАЗ КН5-СОХР».

## 3. Новый раздел «Обновления» (GitHub)

```
Обновления
├── Версия: V 8.7.0            (текущая прошивка)
├── Состояние: …               (результат запроса к GitHub)
├── Проверить обновления       → запрос списка релизов в фоне (otaTask)
├── Список прошивок → Прошивки (GitHub): до 5 релизов «tag · дата · размер»
│                     каждый пункт открывает Карточку релиза
├── Карточка релиза: дата/размер, статус (новее/не новее/установлена),
│                    SHA-256 (после проверки), «УСТАНОВИТЬ», «Проверить SHA-256»
├── Установить последнюю       (как раньше: /releases/latest + проверка SHA-256)
├── Режим ArduinoOTA (Wi-Fi)   (AP + ArduinoOTA, порт 8266)
└── Выход из режима OTA        (показывается только когда режим активен)
```
- Список берётся из `GET /releases?per_page=5` с фильтром ArduinoJson (память под
  ответ ограничена), кэш — 5 релизов в ОЗУ;
- установка любой выбранной версии = тот же проверенный путь
  `downloadGitHubFirmware()` (потоковая запись в `Update`, SHA-256 через mbedtls,
  при несовпадении — `Update.abort()`), затем перезагрузка;
- экран прогресса показывается в **любом режиме** (шапка «ОБНОВЛЕНИЕ», крупный
  процент, статус, «Не выключайте питание»);
- при отсутствии интернета/лимите GitHub API выводится причина («нет Wi-Fi»,
  «GitHub HTTP 403» и т.п.).

## 4. Wi-Fi — как и было задумано: просто подключение

- Пароль один и тот же для любой сети — `asd12345` (без ввода, без веб-форм).
- Экран выбора сети переведён на U8g2 (последний экран, остававшийся на старом
  GFX-тексте): шапка, список сетей с полосками уровня сигнала и усечением длинных
  имён, подсказки по кнопкам.
- Подсказки: «КН1/КН2 — выбор, КН3 — подключить, КН4 — отмена, удерж. КН3+КН4 — меню».

## 5. Живая страница «Информация»

Строки обновляются при каждой отрисовке меню: версия, режим (РУЧ/АВТО/ДВИЖ),
состояние MPU, давление в магистрали, Wi-Fi (SSID и RSSI или AP), аптайм и
свободная RAM, число активных ошибок. Раньше это были три статичные строки,
к тому же оформленные как readonly-ссылки (с лишней стрелкой).

## Проверка и сборка

- Сборка: `arduino-cli` 1.5.1, ядро esp32 3.3.11, FQBN
  `esp32:esp32:esp32:PartitionScheme=custom,FlashSize=16M`, `--warnings none`,
  флаг `compiler.c.elf.extra_flags=-Wl,--allow-multiple-definition`.
- Итог: **скетч 1 389 970 байт (8 % от 16 МБ)**, **глобальные переменные
  66 816 байт (20 %)** — рост относительно 8.6.1: +14 КБ flash и +4,4 КБ ОЗУ
  (раздел «Обновления», кэш списка релизов, живые строки меню).
- В прошивке строка версии: `V 8.7.0 FreeRTOS OTA`.

## Установка

- Устройства на 16-МБ карте разделов обновляются по воздуху: меню → «Обновления» →
  «Установить последнюю» (или выбрав конкретную версию в списке).
- Устройства на прежней 4-МБ схеме разделов требуют разовой прошивки по USB.

## Вне рамок этого релиза

- Интеграция с Home Assistant (MQTT/HTTP) — отдельная версия.
- Ввод паролей Wi-Fi на устройстве и веб-форма настройки — не нужны при одном
  фиксированном пароле.
- Пиннинг CA для HTTPS (сейчас `setInsecure()`, целостность обеспечивает SHA-256 релиза).
