# Kamaz-Leveler 8.6.0 — новая типографика и визуализация (U8g2_for_Adafruit_GFX)

Основа: 8.5.9. Тип изменения: **MINOR** (новые возможности UI, обратная
совместимость по OTA-протоколу, таблице разделов и файлу настроек сохранена).

## Что нового

- Полностью новая типографика экранов на **U8g2_for_Adafruit_GFX 1.8.0**
  (UTF-8, кириллица, честные размеры шрифтов вместо растягивания `setTextSize`).
- Новая визуализация главного экрана: статус-строка, 4 карточки подушек с
  крупными значениями (`u8g2_font_inr24`), мини-шкалами давления с цветовой
  индикацией относительно `P.MIN/P.MAX`, обновлённый авиагоризонт с подписями
  шкалы на шрифте U8g2.
- Служебные экраны переведены на единый стиль: шапка-панель, «подпись: значение»,
  нижняя строка-подсказка. Экран OTA показывает крупный процент (inr24),
  калибровка — крупный процент и обратный отсчёт, тест клапанов — таблицу
  результатов с выровненными колонками, Wi-Fi — список сетей с полосками RSSI.
- Новый модульный слой UI: `ui_theme.h` (палитра/сетка), `ui_fonts.h`
  (шрифтовая лестница `UiFont`), `ui_text.h/.cpp` (класс `UiText`, экземпляр `ui`).
- Отказ от неиспользуемых GFX-шрифтов (`FreeMono6`, `TimesNRCyr7`,
  `CrystalNormal7`); для пунктов меню GEM оставлены `CourierCyr7`/`CourierCyr9`.

## Исправления (перенесено из незакоммиченной 8.5.9)

- Меню: `displayDirty` выставляется при входе в меню из теста, режима OTA и
  fallback-AP (раньше экран меню мог не перерисоваться после гейтинга 8.5.9).
- Меню: `gem.registerKeyPress()` вызывается под `xDisplayMutex` — устранена
  возможная гонка отрисовки между `buttonTask` и `displayTask`.
- Прогресс-бар: дорожка + заливка + рамка вместо полупрозрачной заливки на фоне.

## Проверка и сборка

- Сборка: `arduino-cli` 1.5.1, ядро esp32 3.3.11, FQBN
  `esp32:esp32:esp32:PartitionScheme=custom,FlashSize=16M`, `--warnings none`.
- Итог: **скетч 1 375 590 байт (8 % от 16 МБ)**, **глобальные переменные 61 952 байт
  (18 %)** — рост относительно 8.5.9: +65 КБ флеша (шрифты U8g2), ОЗУ +0.1 КБ.
- Обязательный флаг сборки (см. `build.cmd` и README):
  `--build-property compiler.c.elf.extra_flags=-Wl,--allow-multiple-definition` —
  библиотека GEM тянет `U8g2`, чей `u8g2_fonts.c` дублирует символы шрифтов.
  Без флага сборка падает на линковке (`multiple definition of 'u8g2_font_...'`),
  поэтому собирать нужно через `build.cmd` / `arduino-cli` (не через Arduino IDE 2).

## Установка

- Устройства на текущей 16-МБ карте разделов обновляются по воздуху (OTA:
  меню → «Проверить GitHub» либо кнопкой).
- Устройства на прежней 4-МБ схеме требуют разовой прошивки по USB (смена карты
  разделов по воздуху не переносится).
